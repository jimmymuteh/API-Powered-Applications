# API-Powered Applications

A small collection of browser-based tools that fetch and display live public data using JavaScript. No backend servers, no hidden configurations, and no API keys required.

## What's Inside

1. **Clinical Trials Finder** (`surgeon.html`) — Built for medical professionals. It queries the ClinicalTrials.gov API v2 in real-time to search active clinical research and trial statuses for complex conditions like glioblastomas, aortic dissections, or spinal deformities.
2. **Crypto Price Tracker** (`crypto.html`) — Pulls live USD prices and 24-hour market trends using the CoinGecko API.
3. **City Weather Finder** (`weather.html`) — Fetches real-time temperature and weather conditions anywhere using Open-Meteo.
